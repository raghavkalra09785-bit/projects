# 💰 Expense Tracker

A beautiful, simple, and functional expense tracking website to help you manage and organize your daily expenses.

## Features

✨ **Core Features:**
- 📝 Add expenses with description, amount, category, and date
- 📊 View all your expenses in a clean, organized list
- 🎯 Filter expenses by category or month
- 💾 All data is saved locally (using browser's localStorage)
- 📊 See summary statistics (total, count, average)
- 📥 Export expenses to CSV format
- 🗑️ Delete individual expenses or clear all at once

## Technology Stack

- **HTML5** - Structure
- **CSS3** - Modern styling with gradients and animations
- **JavaScript (ES6+)** - Functionality and interactivity
- **LocalStorage API** - Client-side data persistence

## How to Use

1. **Open the website:** Simply open `index.html` in your web browser
2. **Add an expense:** Fill in the form with:
   - Description (what you spent on)
   - Amount (how much you spent)
   - Category (type of expense)
   - Date (when you spent it)
3. **View expenses:** All expenses appear in the list below
4. **Filter:** Use the filter section to view specific categories or months
5. **Export:** Download your expenses as a CSV file for use in Excel/Sheets
6. **Delete:** Remove individual expenses or clear all at once

## Data Storage

Your expenses are stored in your browser's **localStorage**, which means:
- ✅ Data persists between sessions
- ✅ No server needed
- ✅ Your data stays private on your device
- ⚠️ Data is lost if browser cache is cleared

## Features in Detail

### Summary Dashboard
- **Total Expenses:** Sum of all expenses
- **Number of Expenses:** Count of expense entries
- **Average Expense:** Average amount spent per expense

### Filtering
- Filter by category to see spending in specific areas
- Filter by month to analyze spending patterns
- Reset filters to view all expenses

### Export Data
- Download all expenses as CSV
- Compatible with Excel, Google Sheets, and other spreadsheet software
- Filename includes the current date

### Data Security
- All data stored locally - never sent to any server
- Secure deletion options with confirmation
